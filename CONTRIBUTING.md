# Contributing to Fluxo Engine

Thank you for your interest in contributing to Fluxo! We welcome contributions from everyone. Whether you are fixing a bug, updating documentation, or proposing a new feature, your help is highly appreciated.

Here is a guide on how you can contribute to the development and growth of Fluxo.

---

## How to Contribute

### 1. Reporting Bugs & Suggesting Features
If you find a bug or have an idea for a new feature, please open an Issue:
- Go to the **Issues** tab on GitHub.
- Click **New Issue**.
- Provide a clear description, reproduction steps (if it's a bug), and the expected behavior.

### 2. Contributing Code Changes (Pull Requests)
If you want to write code to fix a bug or implement a feature:

1. **Fork the Repository**: Create your own copy of the repository on GitHub.
2. **Clone the Fork**: Clone the project to your local machine:
   ```bash
   git clone https://github.com/your-username/Fluxo.git
   cd Fluxo
   ```
3. **Install Dependencies**: Install the required development packages:
   ```bash
   npm install
   ```
4. **Create a Branch**: Create a feature branch for your changes:
   ```bash
   git checkout -b feature/my-amazing-feature
   ```
5. **Write Your Code**: Apply your fixes or features.
   - Keep your code clean and document public functions.
   - Ensure there are **no comments** of any kind inside example HTML files.
6. **Build & Test**: Compile the project locally and verify there are no compilation errors:
   ```bash
   npm run build
   ```
7. **Commit & Push**: Commit your changes and push them to your fork:
   ```bash
   git add .
   git commit -m "feat: add my amazing feature"
   git push origin feature/my-amazing-feature
   ```
8. **Submit a Pull Request**: Open a PR from your branch to our `main` branch. Provide a description of what your changes accomplish.

---

## Code of Conduct
- Be respectful, helpful, and welcoming to all contributors.
- Keep discussions constructive and focused on improving the library.

Thank you for helping make Fluxo better!
